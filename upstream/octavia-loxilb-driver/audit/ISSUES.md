# Upstream issues and dispositions

Priorities describe impact on reuse for the Viettel IDC target, not an upstream
maintainer's release priority. Source references are relative to `original/`.

| Priority | Defect | Source/test evidence | Impact | Recommended disposition |
|---|---|---|---|---|
| P0 | Provider-agent entry point exports an absent class | `pyproject.toml:65-66`; empty `controller/worker/__init__.py`; entry-point load fails | Async lifecycle worker may not start through the declared plugin entry point. | Replace packaging/worker boundary; add entry-point load smoke test. |
| P0 | Duplicate LB orchestration | `provider_driver.py:252-291,328-347` runs TaskFlow then casts RPC | Duplicate creates/deletes, races, ambiguous status ownership, and cleanup risk. | Replace with one durable asynchronous orchestration path. |
| P0 | Reconciliation is incomplete | `state_reconciler.py:245-312` assumes members exist and leaves orphan scan as TODO/`pass` | Drift and orphaned configuration cannot be detected or repaired reliably. | Build new desired/actual reconciler backed by durable state. |
| P0 | Health status is hard-coded `ONLINE` | `healthmonitor_driver.py:600-610`; four status unit failures | Octavia can report healthy resources despite disabled, absent, degraded, or error states. | Replace status model and validate against actual API/dataplane state. |
| P0 | L7 surfaces are false-positive paths | Provider casts and logs success (`provider_driver.py:1057-1300`); subdriver is no-op (`loadbalancer_driver.py:629-721`); queue endpoints raise `NotImplementedError` | Requests can be accepted before failing asynchronously or doing nothing. | Explicitly reject L7 until a tested mapping exists. |
| P1 | LoxiLB list response schema drift | Client expects `lbServices` (`loxilb_client.py:458-477`); fixtures use `lbAttr`; three tests fail | Reads return empty and can break get/delete/reconciliation. | Validate the target LoxiLB OpenAPI/runtime schema; add contract tests/version adapter. |
| P1 | Provider invokes missing methods | `provider_driver.py:299-310,927-942`; no `failover` or `get_stats` in `loadbalancer_driver.py` | Failover and statistics fail at runtime. | Do not advertise; implement only after capability validation. |
| P1 | Member/HM coordination invokes missing methods | Unit failures for `_get_pool_health_monitors` and `remove_member_endpoint_probe`; methods absent from HM driver | Member deletion can leave probe state or fail. | Redesign reconciliation boundary and add coordination tests. |
| P1 | Unsupported choices silently fall back | `mapper.py:94-115,368-386,443-471` | User intent changes silently: unknown algorithm→RR, protocol→TCP, cookie→source-IP. | Validate early and raise Octavia `UnsupportedOptionError`. |
| P1 | Updates delete/recreate services | Listener/member/pool paths log service recreation; unit tests expose failures | Brief downtime, connection loss, and poor rollback/idempotency. | Use target API patch/replace semantics behind reconciliation; document unavoidable disruption. |
| P1 | Deletes can hide failure and remove mappings | API list/delete and subdriver exception paths return empty/continue in several locations | Octavia may lose identity while LoxiLB state remains. | Persist operation intent, fail explicitly, and reconcile tombstones. |
| P1 | Retry layers overlap | urllib3 policy plus Tenacity on `_make_request()` (`loxilb_client.py:118-151,248-354`) | Multiplied latency and possible write replay; POST is excluded in one layer but retried in the other. | One operation-aware retry policy with idempotency keys or read-after-write. |
| P1 | Packaging dependencies are inconsistent | `pyproject.toml:31-39`, root/nested requirements, nested setup; declared-dependency collection fails on undeclared `octavia` | Installation outcome depends on host; plugin import fails in isolation. | Define one build metadata source and an explicit supported Octavia compatibility matrix. |
| P1 | TLS termination is only represented as references | `mapper.py:593-618`; listener code stores/passes reference IDs; no Barbican secret retrieval/install path | TERMINATED_HTTPS cannot be considered implemented; reference leakage to LoxiLB schema is possible. | Explicitly reject initially; design secure secret retrieval and rotation later. |
| P2 | Startup health check is unreachable during init | Intended code is inside no-op `update_loadbalancer_status()` (`provider_driver.py:176-207`) | Driver can initialize without intended connectivity validation. | Move validation to a deliberate readiness path; avoid blocking imports on transient dependency state. |
| P2 | Configuration code contains duplicate/inconsistent fields | `common/config.py:174-181` repeats `default`; samples contain keys not registered; `loxilb.conf.sample` is empty | Confusing deployment, warnings, or invalid configuration. | Generate sample config from registered options and test parsing. |
| P2 | Driver version constants disagree | package `version.py` is 1.0.3; `common/constants.py:169` is 0.1.0; nested setup is 0.1.0 | Misleading user-agent/status/support data. | Use package metadata as the single version source. |
| P2 | Duplicate definitions and broad quality debt | Four Flake8 `F811` findings, 49 Black rewrites, 35 unit failures | Later definitions shadow earlier behavior and complicate safe reuse. | Extract only selected components with characterization tests; do not bulk-copy. |
| P2 | Plain pytest collects nothing | `pyproject.toml:99-105` points to root tests; integration class name does not match `Test*` | Default CI can falsely appear empty and documentation test counts are misleading. | Make unit collection explicit in CI and separate environment-gated functional markers. |
| P2 | Production/HA/performance claims lack evidence | `README.md:12-16,205-212`; Phase A test evidence | Risks presenting unverified behavior as production-ready. | Treat as claims until standalone, E2E, HA, scale, and benchmark evidence exists. |
